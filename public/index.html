FAQ & Details How permanent configuration works

Where are configuration files saved?

• Claude Code: ~/.claude/settings.json
• Codex CLI: ~/.config/codex/config.json
• Aider: ~/.aider.conf.yml
• OpenCode: ~/.config/opencode/opencode.json

How does automatic backup work?

Before any configuration file is created or replaced, the command checks if an existing file is present and duplicates it to a timestamped .bak-YYYYMMDD-HHMMSS backup file.

Is my API key stored online?

No. Keys are only used locally in memory for model discovery and inserted into the terminal command you copy. There is no remote database or tracking.
